# CAT_analysis
Exploratory data analysis of the results from using Botanical Gardens Conservation International (BGCI)'s Climate Assessment Tool (CAT) to analyze the University of British Columbia Botanical Garden's holdings.

Data cleaning workflow.
1. import csv
2. remove first 3 lines (header) and last 33 lines (footer)
3. remove sparse rows (8)
4. remove redundant columns (status, created_date,  )
5. remove duplicates
